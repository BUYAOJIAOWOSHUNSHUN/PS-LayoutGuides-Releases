# PS-LayoutGuides-Releases

Adobe Photoshop UXP 插件的源码与在线更新源。

## 目录结构

- `manifest.json` —— 插件清单。**面板的「检查更新」是从这里的 `version` 读远端版本号的**，
  所以每次发新版必须改这个值。
- `index.html` / `styles.css` —— 面板界面
- `bootstrap.js` —— 入口
- `src/` —— 逻辑模块
- `assets/` —— 图标资源（PNG，更新时按二进制写入）
- `docs/` —— 接口笔记

## 发新版要做什么

1. 改 `manifest.json` 里的 `version`（例如 `1.8.0` → `1.8.1`）。
2. 同步改 `src/update-config.js` 里的 `VERSION`，两处必须一致。
3. 提交。想按 Release 发布就再打一个 tag（如 `v1.8.1`）；
   没有 Release 时插件会自动退回默认分支最新提交。

## 更新机制

面板底部点「检查更新」→ 出现「下载并安装更新」→ 第一次需要选一次插件所在文件夹
（之后会记住）→ **完全退出并重启 Photoshop**，新版本才生效。只关面板不算。

更新是按文件逐个从 raw 地址拉取覆盖，不是下载 zip —— UXP 没有解压能力。
所以仓库里不要放 zip。

## 注意

- 仓库必须是**公开**的。更新逻辑不带访问令牌，私有仓库读不到（会报 404）。
- 如果插件装在 `C:\Program Files` 下且 Photoshop 没有提权，自动更新会因为目录不可写而失败。
  这时面板会出现「打开发布页」按钮，可以手动下载覆盖。

# 品牌版式标准规范 PS 插件 v2.1.4

基于 [v2.1.3](https://github.com/BUYAOJIAOWOSHUNSHUN/PS-LayoutGuides-Releases/releases/tag/v2.1.3) 更新。需要 Photoshop 2026（27.0）或更高版本。

## 本次改动

- 在“生成辅助线”下方、底部辅助线控制上方增加导航器缩略图，完整显示当前画布，按原比例居中。
- 通过 Photoshop Imaging API 读取合成预览，不修改文档、图层、历史或保存状态。预览像素最多 480×240，透明区域用白底显示；缩略图不包含 Photoshop 界面的辅助线与选区叠加。
- 随文档切换、内容编辑、撤销和图层显隐刷新。沿用面板的 1.2 秒检查周期，内容未变时不重复读取像素；历史标识或图层可见性无法完整读取时使用 5 秒慢刷新。面板隐藏时停止读取，后台旧结果不会显示到新文档上。
- 导航器下方增加缩小按钮、缩放滑条、放大按钮和百分比。拖动时显示目标百分比，结束操作后应用 Photoshop 文档视图缩放，不修改像素尺寸。
- 缩略图上增加红色可见区域框，拖动红框可移动 Photoshop 主画面。外部缩放或平移后自动跟随；视图读取与像素预览分开，移动视图不重复生成缩略图。
- 导航器区域缩小为最多 180px 高，空间不足时收紧至最低 120px，并减少上下间距。两页共用按 RGB 页内容预留空间计算的高度，避免切换页签时预览伸缩；极短窗口仍可滚动查看完整操作。
- CMYK出血设置区域以RGB图片/画布参数区的高度为基准，较短的部分在出血设置下方留空，使生成辅助线、导航器及底部控制区域的位置与RGB页对齐。面板宽度或大小摘要变化时同步更新留白。
- 暂时无法读取时只在预览区域提示，不禁用尺寸、辅助线和导出功能；内容刷新继续保留未提交的尺寸输入。
- PSD／TIFF 按钮改为将当前文档“储存为”，保存后由 Photoshop 更新文件名、路径与保存归属。原生“现在保存”及储存为完成后重新读取活动文档，短暂等待实际保存状态更新；取消或未确认完成时保留红字。
- 在“打开文件夹”右侧增加“保存”按钮，直接调用 Photoshop 原生保存。首次保存打开原生保存窗口；已有文件保存到原位置。保存完成后刷新红色“未保存”提示，取消或失败时保留实际状态。

透明区域在插件预览中使用白底。旋转视图或无法可靠读取屏幕坐标时暂时隐藏红框，缩略图与缩放功能继续可用。

## 保留的功能

- 图片大小锁定比例时，输入宽度或高度即时换算另一边，点击“修改”才修改文档。
- 实时显示预计图像大小与修改前大小，按像素、颜色通道和位深估算；不等于包含图层与压缩后的 PSD 磁盘文件大小。
- 图片和画布按钮统一为“修改”。删除、显示/隐藏辅助线固定在底部，旁边增加锁定/解锁小按钮。
- 浮动面板允许左右伸缩，宽度范围 400–520 像素，默认 420。
- RGB / CMYK 前标注“模式”，导出区前标注“导出”，格式之间增加分隔线。JPG 使用质量 12；PNG 调用 Photoshop“文件 → 导出 → 快速导出为 PNG”。
- 检查更新区分线上最新版与本地测试版，并显示具体失败原因。请求与内容读取共用 15 秒超时，版本信息优先使用 GitHub Contents API，安装下载可自动切换备用通道。在线安装先完整下载并备份再写入，写入失败时尝试恢复原文件。

## 快速导出

- 面板布局为上排 `PSD | TIFF`、下排 `JPG | PNG`，左侧“导出”文字垂直居中。
- PSD 将当前文档储存为 `.psd` 并保留图层；TIFF 将当前文档储存为 `.tif`，选择器同时允许 `.tif`、`.tiff`。TIFF 使用 Photoshop 原生储存命令，未另行指定压缩、字节顺序等编码参数。
- PSD／TIFF 保存完成后，当前文件名和路径更新为所选位置，后续保存使用该位置。代码不主动拼合图层或转换颜色模式、位深；取消或报错后恢复面板操作。TIFF 原生选项和图层大小提示由 Photoshop 显示，可直接确定使用默认设置。
- JPG 使用最高质量 12，保持当前像素尺寸，保存位置由用户选择。支持 RGB、CMYK 和灰度；16 位文档仅将导出副本转成 8 位，32 位及不支持的模式会提示无法导出。
- JPG 在临时副本中处理，保存失败或取消时清理副本，原文档的图层、模式和尺寸保持不变。
- PNG 直接调用 Photoshop“文件 → 导出 → 快速导出为 PNG”，不再经过插件的复制、转换及另存 PNG 流程。导出位置、透明度、色彩和位深等遵循 Photoshop 的快速导出设置与原生行为。
- 如果 Photoshop 当前的快速导出格式不是 PNG，面板会提示先将其设置为 PNG；插件不会自行修改导出首选项。状态栏“已调用”表示已交给 Photoshop 处理，实际保存结果以 Photoshop 为准。

“打开文件夹”的首次系统授权请按需勾选“记住我的选择”后点“允许”，授权由Photoshop管理；插件没有后台自动批准授权的接口。本次同一测试目录第二次打开没有重复弹窗，不能保证不同目录、重装或其他宿主版本的授权复用行为。

## 参考线颜色

- CMYK 模块的出血线使用 Photoshop 洋红预设色；版心线、LOGO 高度线、背书高度线使用青色。
- 创建时直接调用 Photoshop 的原生彩色参考线命令，沿用面板中已填写的尺寸，无需再填写原生窗口。
- 出血线仍从画布四边向内缩，四边数值可独立设置。
- 重新点创建会重建本次插件会话管理的参考线，以恢复指定颜色；不会叠加重复线，也不会认领其它来源的参考线。
- Photoshop 返回的颜色、方向、归属或位置不符时，整次更新回滚。普通 Guide 查询不提供颜色，因此这里核对的是原生创建命令的返回结果。
- “删除辅助线”继续执行已有的清除当前文档全部参考线功能。

## RGB / CMYK 切换

- 点击文档信息右侧的 RGB / CMYK，调用 Photoshop“图像 → 模式”对应的原生命令。
- 明确选择不拼合、不合并、不栅格化。转换前后核对图层结构、类型和文字；不符合保留要求时回滚。
- 一次转换对应一条历史记录；已处于目标模式时不重复转换。
- 若 Photoshop 原生转换会移除某个调整层，插件保留原模式与全部图层并提示该图层名称。本机曲线调整层案例已触发此保护。
- 颜色仍按照 Photoshop 的模式转换规则处理，不保证转换前后色彩完全相同。

## 界面对齐

统一两张尺寸卡的标题、标签和输入行，以及按钮、单位切换、出血设置与页脚的对齐，保留深色面板和现有操作顺序。

## 画布大小

- 输入目标宽高，选择单位和九格锚点，再点“修改”。回车只结束输入，不修改文档。
- 扩展颜色支持前景色、背景色、白色、黑色、中灰和自定颜色。有背景层时只填新增画布；没有背景层时新增区域保持透明。
- 画布修改与填色合为一条历史记录。填色或状态恢复失败时回滚，状态栏说明出错阶段。
- 切换文档、尺寸或分辨率变化后，旧输入会刷新。仅辅助线变化时保留画布输入。
- 快速蒙版、选区越过画布边界等无法可靠恢复状态的情况会在修改前中止。

## 独立拾色弹窗

点击扩展颜色色块或选“其它”，打开模仿 Photoshop 布局的 UXP 弹窗：

- 大面积饱和度/明度方块与竖向色相条，支持拖动。
- 新颜色和当前颜色并排预览。
- HSB、RGB、HEX 数值输入联动。
- “确定”保存自定颜色；“取消”、Esc 或关闭窗口保留原颜色。

这是插件实现的精简拾色器，未调用 Photoshop 原生拾色窗口，也不包含吸管、色库或色域警告。

## 安装与升级

正式发布包的安装方式：保存工作并完全退出 Photoshop，双击 CCX，按 Creative Cloud 提示操作；完成后重新打开 Photoshop，通过“增效工具”菜单打开面板，检查页脚版本。

手动升级：解压 ZIP，先把已有插件文件夹完整备份到插件目录以外，再将解压所得插件文件夹内的全部内容复制到原安装目录。保留 manifest.json 在安装目录根层，不要多嵌套一层文件夹。重启 Photoshop 后生效。

首次以开发方式加载：使用 Adobe UXP Developer Tool 添加解压所得的 manifest.json，然后加载插件。

插件内的“检查更新”读取 GitHub 正式 Release 与版本信息。发现新版后点击“下载”，首次会显示当前安装位置并打开目录选择器；确认当前插件根目录后保存授权，再自动下载、备份和写入。后续授权仍有效时无需再选目录。更新完成后重启 Photoshop 生效。若在线升级失败，可点“手动更新”打开发布页下载。
